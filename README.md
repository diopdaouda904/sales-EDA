# 🛒 Supermarket Sales — Exploratory Data Analysis

## Description
Analyse exploratoire des données de ventes d'un supermarché 
new-yorkais sur l'année 2024. L'objectif est d'identifier 
les leviers de croissance du chiffre d'affaires et comprendre 
le comportement des clients.

## Dataset
- **Source** : Kaggle - Supermarket Sales
- **Période** : Janvier 2024 - Décembre 2024

- **Taille** : 5053 transactions
- **Variables** : 9 colonnes (date, ville, produit, prix, quantité...)

## Analyses réalisées
- **Analyse univariée** : distributions des variables quantitatives et qualitatives
- **Analyse bivariée** : liens entre CA et caractéristiques du supermarché
- **Analyse temporelle** : CA par jour et par mois
- **Analyse clients** : membres vs clients normaux

## Principaux résultats
- **Home & Lifestyle** est la catégorie la plus rentable malgré un volume de ventes inférieur à l'alimentation, expliqué par des prix unitaires plus élevés
- **Les membres** dépensent en moyenne 210€ par transaction vs 170€ pour les clients normaux (+23%)
- **La satisfaction client** est homogène entre catégories (Rating moyen : 6.9/10)
- **Aucune corrélation** entre prix, quantité et satisfaction — les clients achètent indépendamment du prix
